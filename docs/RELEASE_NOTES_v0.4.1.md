# v0.4.1 预览版

Kitten Space Agency（KSA）是一款仍在开发中的太空模拟游戏。**KSA UI Languages** 为它提供部分简体中文界面，帮助你看懂设置、搭建飞船和操作说明。

**只支持 Windows 64 位和 KSA 2026.10.7.5541。** 没有译文的内容继续显示英文。

## 下载与更新

推荐下载 **KsaUiLanguages-0.4.1-installer4-win-x64.zip**。完整解压、关闭游戏，双击 **Install.cmd**，选择包含 KSA.dll 的游戏目录。随后从桌面 **“KSA 中文版 (5541)”** 启动。

旧版用户按同样步骤更新，选择原来的游戏目录。独立设置和存档会保留，配置和旧插件会备份；安装器**不会自动备份存档**。加载器和私有运行时已包含在包内，安装可离线完成。双击 Install.ps1 可能只会打开记事本，请运行 Install.cmd。

[安装、存档位置与卸载说明](https://github.com/LiX-Works/KsaUiLanguages/blob/v0.4.1/docs/INSTALLER.md)

## 这次补了哪些地方

- **规划与轨迹**：飞行计划、轨迹段、机动编辑及右键菜单；轨道转移、星际航行与修正机动；地面轨迹和目标轨迹。
- **部件与资源**：操控、聚焦、对接和目标设置；储箱供给顺序及推进剂转移；资源分组、推进剂管线、电池和发电、用电装置。
- **存档与对象清单**：列表、筛选与表头、新建存档提示、载入与覆盖确认；回收、清除残骸和原版对象类型名称。
- **零散提示**：重启、更新、启用模组和选择飞船等常用弹窗；补充时间单位，修复共享控件中部分译文未生效的问题。
- **校对字典**：1,480 条记录，602 条带有语义备注，比 v0.4.0 增加 464 条。进一步区分轨道半径与高度、电量与功率等容易混淆的词句。

常用缩写、单位、快捷键和玩家名称保留。Language 菜单可以即时切换中英文，选择只对本次运行生效。
