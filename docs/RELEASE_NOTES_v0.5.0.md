# v0.5.0 预览版

Kitten Space Agency（KSA）是一款仍在开发中的太空模拟游戏。**KSA UI Languages** 为它提供部分简体中文界面，也可以切回英文。

本版支持 **Windows 64 位、KSA 2026.10.7.5541 和 2026.10.10.5554**。

这次将当前版本统一编号为 **v0.5.0**，功能与 v0.4.2 一致。以后按 **v0.6.0、v0.7.0** 递增，旧标签和下载文件保留。

## 下载与更新

推荐下载 **KsaUiLanguages-0.5.0-installer5-win-x64.zip**。完整解压，关闭游戏，双击 **Install.cmd**，选择包含 KSA.dll 的游戏目录，再从桌面的 **KSA 中文版 (5554)** 或 **KSA 中文版 (5541)** 启动。

同版本更新汉化时，选择原游戏目录即可；独立设置和存档会保留，配置和旧插件会备份。安装器不会自动备份存档。

换到 5554 时会创建 Build5554 独立实例，保留 Build5541。游戏本体需另行准备；汉化安装器不会升级游戏或自动迁移旧存档。不要将跨版本实例强行安装到同一目录。

[安装、存档位置与卸载说明](https://github.com/LiX-Works/KsaUiLanguages/blob/v0.5.0/docs/INSTALLER.md)

## 本版内容

- **5554 适配**：54 项语言与控件检查通过，并实际检查启动、主要窗口、中英文切换和测试存档保存/载入。
- **欢迎和加载画面**：入门说明、中文换行、原快捷键卡片、主要加载阶段及显存提示。
- **部件和资源**：降落伞预备、部署、解除收口及切伞提示；资源、燃烧室、喷管和药柱参数；资源流动图。
- **编辑器和乘员**：补满消耗品、自动分组、资源管理；乘员状态、头像相机、EVA 动作与天体悬停说明。
- **储箱名称和字典**：新增 32 个储箱名，目前 52 个部件有名称映射。字典共 1,625 条，其中 748 条有语义备注。部件型号和原 ID 保留，后续命名方案仍待核查。
- **升级预检工具**：比较补丁目标、规范化原始指令和常量变化，方便以后定位新版改动；工具通过不等于运行兼容。

## 检查和已知问题

同一发行插件在 5541、5554 上均通过 **54 项检查**。5554 已实机查看欢迎页、飞行计划、转移规划、编辑器、资源分组和中英文往返；独立存档成功保存并重新载入。安装器在 5541 上通过 **18 项**、5554 上通过 **16 项**流程检查，覆盖安装、重装、跨版本拒绝、备份和卸载。

长存档名在载入确认弹窗中可能被截断。版本历史、部分 HUD 短标签、调试和深层界面仍有英文。尚未全面验证所有操作、长时间运行、第二台电脑及旧存档迁移。词条数量不代表全游戏汉化完成。
