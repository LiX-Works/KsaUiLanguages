KSA UI Languages v0.2.0 是基础 UI 汉化和多语言框架的预览版。

**仅支持 KSA 2026.10.7.5541、StarMap 0.4.7、Windows x64。**

- 202 条原生资源译文，覆盖多个设置页面和提示。
- 主菜单、暂停菜单、设置下拉选项和部分面板标题中文显示。
- 资源栏液氢、液氧、电能，以及 78 条中文悬停说明。
- 游戏内 English / 简体中文即时切换，缺失译文回退原文。
- 保留常见飞行缩写及单位。

下载 **KsaUiLanguages-0.2.0-build5541.zip** 即为可安装插件；source ZIP 是源码。SHA256SUMS.txt 提供校验值。安装步骤与卸载方法见 [README](https://github.com/LiX-Works/KsaUiLanguages#安装)。

独立代码与译文采用 MIT；字体子集采用 SIL OFL 1.1。游戏、StarMap 与其依赖需另外取得，下载包只包含本插件、语言文件、字体及许可证。

11 项使用实际游戏语言对象和原生 ImGui 哈希的检查通过；主菜单、暂停菜单、设置下拉、资源栏、中英切换和 ORBT 悬停说明做过实机检查。仍有许多仪表按钮和深层界面未覆盖，长期稳定性及其他游戏版本尚未验证。

English: Independent partial UI localization for KSA build 5541. Chinese and English switching, scoped menu/settings/resource text and tooltips. Install the build5541 ZIP via StarMap 0.4.7. MIT code/translations; OFL font. This is an unofficial prerelease.
