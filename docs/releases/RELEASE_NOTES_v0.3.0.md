v0.3.0 扩展了飞船编辑器的基础 UI 汉化；仍固定适配 **KSA 2026.10.7.5541 / StarMap 0.4.7 / Windows x64**。

- 放置、平移、旋转、缩放工具及部件分类。
- 自由 / 环绕相机、正交 / 透视投影、对称继承和吸附工具。
- 切换飞船、乘员分配、飞船名称、发射天体 / 地点。
- 部件提示卡中的质量、容积、电力、推力、Isp、供料对象和分离力。
- 扩展编辑器悬停说明。
- 补充树状字符，修复提示卡前缀缺字；补入地球 / 月球等发射天体与地点格式、双基推进剂译名。

熟悉的飞行缩写、单位、部件原始编号及发射场编号保持可辨认。深层编辑器、部件命名和其他零散界面仍待补充。

**下载选择**

- **KsaUiLanguages-0.3.0-installer2-win-x64.zip**：推荐。完整解压后运行 Install.cmd；含加载器与私有运行时，可离线安装。
- KsaUiLanguages-0.3.0-build5541.zip：仅插件，供已配置 StarMap 的玩家手动安装。
- KsaUiLanguages-0.3.0-source.zip：本版本源码。
- SHA256SUMS.txt / INSTALLER-SHA256.txt：校验文件。

已经使用旧一键安装包的玩家，关闭游戏后运行新版 Install.cmd，选同一游戏目录即可更新默认安装，保留独立配置与存档并备份。使用项目私有测试配置的玩家，下次运行 start_prototype.ps1 会自动复制最新插件。
