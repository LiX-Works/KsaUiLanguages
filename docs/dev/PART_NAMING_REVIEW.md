# 部件命名待办与原版依据

用户反馈：现有名称强调尺寸和型号，难以看出用途及具体区别；其他许多部件仍显示内部 ID。此条先记录，不修改译名、字典或游戏数据。

## 原版有没有更好的英文名

对本机 2026.10.7.5541 的 Core XML 核对：177 个预制部件中，19 个有显式 DisplayName，158 个没有。PartTemplate 加载时会把空 DisplayName 回退为 Id。因此大量 `Core…_Prefab_…` 确实是原版显示来源，并非汉化漏读了一份完整的英文部件名表。

有官方名时优先翻译官方名。例如 LR91 Sea、LR91 Vac、Fuel Port、MRS-1 Magnetic Scoop。没有官方名的部件需要按游戏数据和实际外观重新拟名，不能仅按 ID 缩写猜含义。

## 截图中的 NoseconeE

`CoreFairingA_Prefab_NoseconeE` 在 Assets 和 GameData 中均未设置 DisplayName。GameData 标注 Fuel Tanks、Diameter=1 m，包含有流体连接能力的接口和 ConicalTank，另有尖拱形壳体质量模型。

它是带推进剂储存功能的头锥，不能只称为外观整流件。同系列中 A、B、D 只有结构壳体数据，C、E、F 则带储箱。用途差异值得优先体现在名称或说明中。

依据：`Content/Core/CoreFairingAGameData.xml` 的 NoseconeA–F；其中 E 从第 542 行开始。Assets 的 E 引用 NoseconeBallistic1M 模型，并有底部连接器。截图显示的 167.56 kg 和 2.55 kL 是该次游戏界面的读数，此处不重新推算。

## 储箱哪些是外观变体

对 32 个普通 CoreFuelTankA 与 4 个 CoreFuelTankB 的静态复核：

- 同几何规格的 A/B/C/D 通常共享储箱、碰撞体、材料和壁厚数据，主要替换外壳模型。暂未发现其容量或默认供给角色差异；外观颜色和涂装还需看模型，不能仅凭字母命名。
- LF 系列通常是单圆柱储箱，默认供给角色为 Engine；MP 系列为四个圆柱储箱，显式角色为 Thruster。它们在结构和默认供给对象上有区别。
- 这里的角色是资源供给优先匹配，不是只能装某一种燃料。普通储箱的接纳条件主要区分是否需要磁约束，不能把 LF/MP 擅自展开成特定燃料类型。
- 短外形不保证容量按比例缩小。根据当前几何计算，双穹顶会限制最小长度：LF1WHalfH 与 LF1W1H、LF2W1H 与 LF2W2H 的计算容积可能相同。此项属于源码公式推导，仍需按同样缩放条件实机核对。

详细结构、源文件哈希、规格组和计算假设记录在 `work/inspect/naming-review-20261007/fuel-differences.json`。这不是已测试所有飞行性能的结论。

## 后续命名原则（待实施）

先告诉玩家“是什么、有什么用”，再描述真正有用的区别，最后保留尺寸和型号。可考虑把主发动机/姿控供给、单罐/多罐、内置储箱、结构件/可分离件等区别放在说明里。

同功能同规格而仅外观不同的变体，适合保留共同名称，再用经过视觉核实的外观特征区分。内部型号可保留在次要位置，便于定位和报错。暂不承诺用字母代号推断品牌、燃料限制、隔热或强度。

本轮只记录和核查，没有应用新的名称方案。

## 用户补充的命名风格

以“信、达、雅”为目标。这里的“雅”包括自然、易读、好记、贴近玩家，不要求所有名称都严肃，也不只是压缩字数。用户随后明确补充：不要刻意搞怪，避免让名称显得尴尬；以克制、实用、能看出部件区别为主。

- **信**：功能、容量、供给角色、材质和性能以原版数据为准。不能为好听而暗示不存在的用途、增益或限制。
- **达**：名称先让玩家看出是什么、与邻近零件有什么区别。尺寸和内部型号不承担主要解释作用。
- **雅**：采用自然的玩家用语，同系列保持一致风格；不强行设计笑点，不批量起俏皮外号。
- 如果官方原名本身有自然的幽默或双关，可在不影响理解的前提下保留。没有必要为了有趣而增加新的昵称。
- 用户进一步指出：生硬模仿中文梗或凭外形硬起可爱外号容易显得尴尬。默认不主动造梗；涉及幽默时先核对原名出处、语境和已有惯用说法，拿不准就采用朴素而贴切的描述。
- 涉及容量、耐热、可靠性或动力等判断时，需要额外数据依据；外形长短不等于容量高低。
- 展示优先采用“功能或结构特征＋部件类别”的主名称，尺寸、型号和更详细参数放在合适的次要位置。先核对界面可用空间和原版显示机制，再决定具体形式。

有明确官方英文名时优先理解其原有含义、梗和风格；只有内部 ID 时，再结合数据、模型和实际用途拟名。后续校对同时检查技术准确性与中文表达，不只按长度或字面对应判断。当前仍先记录，不修改已有译名。
