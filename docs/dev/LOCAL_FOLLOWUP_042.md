# 本地补译 0.4.2-local

这一轮继续检查 v0.4.1 的遗漏，补充普通玩家会遇到的提示和部件详情。本地版本适用于 KSA 2026.10.7.5541，尚未发布。

- 欢迎页：入门说明、实际快捷键卡片和“每次启动时显示”。中文按字符拆分换行，标点与相邻文字一起处理；原快捷键卡片和设置回调保留。
- 加载画面：主要阶段、渲染初始化和着色器提示，并将 VRAM 前缀译为“显存”。文件路径、模型和着色器标识、原数值与单位保留。
- 降落伞：伞衣直径、展开高度、预备/取消预备、强制展开、解除收口、切伞，以及展开状态和安全条件说明。
- 部件与资源详情：质量、储存温度、密度、体积、电量、质量流率、燃烧室与喷管参数、固体药柱状态和资源流动图开关。
- 乘员与视图：无飞船/无座位提示、乘员头像相机选项、EVA 抓握/松开/进入飞船提示、天体悬停说明和银河坐标标注。

字典共 **1586 条**，比 v0.4.1 增加 **106 条**；其中 **709 条**有语义备注。新增条目归入 utility 和 tooltips，校对文件在 `work/exports/followup-042`。

**52 项语言与控件检查通过**。新增检查包括欢迎页原快捷键对象及段落保留、中文分行、加载状态只读、资源流动图的作用范围恢复、降落伞和乘员头像控件的原生 ID 哈希及英文回退。

已用独立实例实际启动游戏。日志确认插件加载、游戏初始化完成，stderr 为空。截图工具两次返回 `FrameArrived timed out`，因此本轮新增界面的实际排版尚未确认，不能把构建或日志成功视为完整视觉验收。

关闭游戏后，可从本机桌面的 **KSA 中文测试（本地）** 入口试用。普通玩家的正式安装包仍是 v0.4.1。本轮没有更改原版游戏文件、原玩家设置或星舰独立实例。

仍待检查：更深层的工程调参页、固体发动机的特殊错误提示、第三方模组窗口、较窄窗口的排版，以及所有实际操作与长时间运行。
