# 本地界面补译记录

本文记录 v0.4.1 发布前的本地界面补译与检查，测试阶段版本为 **0.4.1-local**，适用于游戏 **2026.10.7.5541**。正式版的安装与更新说明见 [v0.4.1 发布说明](RELEASE_NOTES_v0.4.1.md)。

## 本轮覆盖

| 界面 | 补译内容 |
| --- | --- |
| 飞行计划与机动 | 轨迹段、轨道参数、遭遇事件、机动编辑和右键菜单，以及部分时间读数 |
| 轨道转移规划 | 转移类型、出发与目标条件、计算结果、星际转移、修正机动及推进剂不足提示 |
| 地面轨迹与目标轨迹 | 视图菜单、显示模式、相对位置、最接近点、机动编辑和提示 |
| 部件与对接 | 操控、聚焦、对接、解锁、目标设置、储箱取用与转移、供给顺序及地图控制 |
| 资源分组与详情 | 分组菜单、推进剂管线、电池、发电和用电装置、太阳能板及储箱字段 |
| 游戏与飞船存档 | 列表、排序表头、刷新、新建、载入、覆盖、删除及文件名提示 |
| 对象清单 | 对象类型筛选、显示列、轨道高度、SOI 半径、回收与清除残骸提示 |
| 常用弹窗 | 放弃、重启、更新、启用模组和选择飞船等提示 |

字典新增 `planning` 和 `utility` 两个区段，区分轨道规划与其他常用窗口。比如飞行计划的近点读数是半径，对象清单的近点读数是高度；目标轨迹图的 Period 是显示周期数，轨道信息中的 Period 是轨道周期。

## 怎样试用

普通玩家请使用正式离线安装包，安装后从 **KSA 中文版 (5541)** 启动。开发期间本机使用 **KSA 中文测试（本地）** 入口读取项目中的最新补丁；该入口不是安装包的一部分。

本地字典在 `work/exports/comprehensive-local`，包含 JSON、CSV 和校对说明。JSON 与 CSV 均有可选“备注”，说明界面位置、功能和容易混淆的含义。校对者的改写建议放在独立的 reviewer_notes / proposed_translation 字段。

当前字典共 1480 条，比公开的 v0.4.0 增加 464 条；602 条带有语义备注。数字表示字典记录数，不是已实看窗口数。

## 检查方法与边界

程序扫描了 17,425 个方法，找到 1,053 个直接调用界面控件的方法和 3,986 条候选文本。候选中包括内部 ID、格式和拼接片段，数量不等于漏译词条数，也不用于计算汉化百分比。对常用功能逐项阅读实际调用点，再增加显示层补丁。

检查包括真实游戏对象、中英文回退、动态名称保护、原生 ImGui ID 哈希、数值格式、共享控件组合和全部补丁安装。47 项检查通过，记录在 `work/run-logs/language-checks.json`。另用独立测试实例实际启动游戏，查看飞行计划、转移类型下拉菜单、存档列表和新建存档提示、对象清单及更新弹窗。中文可见且没有显示内部 ID 尾缀；没有执行保存、删除、回收或转移机动。这些检查不能代替每个按钮的实机操作和全部窗口排版验收。

常用模拟器缩写、单位、快捷键和玩家名称保留。部件模板、存档文件名、模组 ID、计算方法和实际控制逻辑不按翻译词条改写。
