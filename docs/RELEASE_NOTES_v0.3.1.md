Kitten Space Agency（KSA）是一款仍在开发中的太空模拟游戏。**KSA UI Languages** 为它提供简体中文界面，帮助你看懂设置、搭建飞船和操作说明。

**v0.3.1 是部分汉化预览版，只支持 Windows 64 位和 KSA 2026.10.7.5541。**

## 下载与更新

推荐下载 **KsaUiLanguages-0.3.1-installer3-win-x64.zip**：

1. 完整解压，关闭游戏。
2. 双击 Install.cmd，选择包含 KSA.dll 的游戏目录。
3. 从桌面“KSA 中文版 (5541)”启动。

旧版用户也按这三步更新，选择同一游戏目录即可；独立设置和存档会保留，配置和旧插件会备份。加载器和运行时已包含在包内，安装过程可离线完成。[详细说明](https://github.com/LiX-Works/KsaUiLanguages/blob/main/docs/INSTALLER.md)

## 新增内容

- 启动配置页汉化，包括天体系统、纹理、阴影与显存提示。
- 首批 20 个部件中文名，覆盖乘员舱、固体助推器、分离器和推进剂箱，同时保留型号。
- 改善部分提示的中文表达。
- 中英对照字典含 737 条记录，其中 160 条补有界面、菜单和功能备注，便于校对与增加语言。

字典存在条目不代表游戏的每个界面都已汉化。部分部件原版没有明确英文显示名，中文按用途拟定，内部 ID 保持原值。
