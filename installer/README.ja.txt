KSA UI Languages v0.6.0 — 日本語インストールガイド

Kitten Space Agency（KSA）は、開発中の宇宙シミュレーションゲームです。
この非公式言語パックは UI の一部を日本語・簡体字中国語で表示し、
英語にも切り替えられます。Windows x64 と、次の KSA バージョンに対応します。
2026.10.7.5541 / 2026.10.10.5554。ゲーム本体は別途用意してください。

使い始めるには
1. KsaUiLanguages-0.6.0-installer5-win-x64.zip をすべて展開します。
2. ゲームを終了し、Install.cmd を実行します。Install.ps1 ではありません。
3. 中国語のフォルダー選択画面が開きます。KSA.dll のあるゲームフォルダーを
   選択し、選択を確定してください。
4. 次の中国語ダイアログにはゲームとインストール先のフォルダーが表示され、
   同梱ライセンスへの同意とインストール開始を求められます。
   LICENSE.txt と licenses フォルダーの内容を確認し、同意する場合は
   「Yes / 是」を選んで続行してください。
5. デスクトップの「KSA 中文版 (5554)」または「KSA 中文版 (5541)」から
   起動します。名前はゲームのバージョンによって変わり、中国語のままです。
6. 最初は簡体字中国語で起動します。ゲーム内で Language → 日本語 を
   選択してください。English にも切り替えられます。
   このメニューでの選択は、ゲームを終了すると保存されません。

必要なローダーと専用ランタイムを同梱しているため、オフラインで
インストールできます。管理者権限は不要です。KSA 本体と Starship MOD は含みません。

更新とセーブデータ
同じゲームバージョンで更新する場合は、新しい Install.cmd を実行し、
元のゲームフォルダーを選びます。設定とセーブデータは保持されます。
設定ファイルと旧プラグインはバックアップされますが、セーブデータの
自動バックアップは行いません。
ゲームのバージョンごとに専用環境を作成します。ゲーム本体の更新、
既存プレイヤー設定の取り込み、旧セーブデータの自動移行は行いません。

通常のインストール先:
%LOCALAPPDATA%\KsaUiLanguages\Build5554 または Build5541
設定・MOD・セーブデータは instance、インストール時のバックアップは
backups にあります。削除するには、ゲームを終了し、この場所にある
Uninstall.cmd を実行します。instance と backups は保持されます。
これらを自分で削除する前に、セーブデータをバックアップしてください。

翻訳は一部のみです。長いリソース名やセーブ名が切れる場合があります。
全画面、長時間のプレイ、別の PC、旧セーブデータの移行は全面的には検証していません。
