# KSA UI Languages

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語**

**Kitten Space Agency（KSA）は、開発中の宇宙シミュレーションゲームです。** この言語パックは、設定、機体エディター、主な飛行ウィンドウなどを日本語・簡体字中国語で表示します。英語にも切り替えられます。

**仕組み**：静的なテキスト差し替えではなく、実行時に動作するローカライズフレームワークです。ゲーム内で言語を即時に切り替えられ、各言語 1,625 項目の辞書（意味の校正メモ 748 件付き）を収録しています。対応する各ゲームバージョンで 59 項目の言語・UI 自動チェックを通過しており、新しいゲームバージョン向けの互換性事前チェックツールも備えています。

**現在のバージョン: v0.6.0 プレビュー版。Windows x64、KSA 2026.10.7.5541 / 2026.10.10.5554 に対応します。** 翻訳は UI の一部が対象です。未対応の画面や訳文のない項目は英語で表示されます。

## ダウンロードとインストール

[v0.6.0 をダウンロード](https://github.com/LiX-Works/KsaUiLanguages/releases/tag/v0.6.0)し、**KsaUiLanguages-0.6.0-installer5-win-x64.zip** を選んでください。

1. 上記の対応バージョンの KSA を用意し、通常どおり起動できることを確認します。
2. ZIP をすべて展開し、ゲームを終了してから **Install.cmd** を実行します。**KSA.dll** があるゲームフォルダーを選択してください。
3. デスクトップの **「KSA 中文版 (5554)」** または **「KSA 中文版 (5541)」** から起動します。名前は選択したゲームのバージョンによって変わります。
4. ゲーム内で **Language → 日本語** を選択します。**简体中文 / English** にも切り替えられます。

インストーラーの案内とショートカット名は、現在も中国語です。同梱ライセンスに同意する場合は、確認画面で **Yes / 是** を選んでください。必要なローダーと専用ランタイムを同梱しているため、オフラインでインストールできます。管理者権限は不要です。Install.ps1 をダブルクリックするとテキストエディターで開く場合があるため、Install.cmd を使ってください。

**同じゲームバージョンで更新する場合**は、元のゲームフォルダーを選択します。設定とセーブデータは保持され、設定ファイルと旧プラグインはバックアップされます。セーブデータの自動バックアップは行いません。

**5541 から 5554 へ移行する場合**は、Build5541 を残して専用の Build5554 環境を作成します。両方のゲームフォルダーを保管してください。このインストーラーはゲーム本体の更新・バックアップや、旧セーブデータの自動移行を行いません。[インストール・セーブデータ・アンインストールの詳細（中国語）](docs/INSTALLER.md)

## 言語と今回の更新

- **3 言語に対応**: 日本語を追加し、簡体字中国語と元の英語を引き続き利用できます。日本語・中国語の辞書はそれぞれ **1,625 項目**で、既存の翻訳機能が扱う設定、エディター、主な HUD、計画、軌跡、セーブ画面、説明文などを対象としています。
- **日本語の案内**: ようこそ画面で仮名や日本語の句読点を含む文章の改行を改善し、表示に必要なフォントの文字を追加しました。
- **識別に必要な表記を保持**: RCS、EVA、Isp、TWR、HUD、Δv などの略語、単位、キー割り当て、パーツの型番、プレイヤーが付けた名前は保持します。

初期設定は簡体字中国語です。**Language メニューでの選択は、ゲームを終了すると保存されません。** 起動時の言語を変更するには、インストール先の `instance/mods/KsaUiLanguages/language.json` で `locale` を `ja-JP`、`zh-CN`、`en-US` のいずれかに設定してください。

## 確認内容と既知の問題

両対応バージョンでそれぞれ **59 項目の自動チェック**に合格し、5554 では日本語の起動設定・読み込み・ようこそ画面を確認しました。一部に英語が残り、長いラベルやセーブ名が切れる場合があります。すべての操作や長時間のプレイは全面的には検証していません。[確認内容と既知の問題の詳細](docs/RELEASE_NOTES_v0.6.0.md)

非公式のコミュニティ製言語パックです。**KSA 本体と Starship 機体 MOD は含みません。** 次回以降の公開バージョンは v0.7.0、v0.8.0 と進みます。[バージョン番号の方針（中国語）](docs/VERSIONING.md)
