# KSA UI Languages

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語**

**Kitten Space Agency（KSA）は、開発中の宇宙シミュレーションゲームです。** この言語パックは、設定、機体エディター、主な飛行ウィンドウなどを日本語・簡体字中国語で表示します。英語にも切り替えられます。

**仕組み**：静的なテキスト差し替えではなく、実行時に動作するローカライズフレームワークです。ゲーム内で言語を即時に切り替えられ、各言語 1,625 項目の辞書（意味の校正メモ 748 件付き）を収録しています。対応する各ゲームバージョンで 60 項目の言語・UI 自動チェックを通過しており、新しいゲームバージョン向けの互換性事前チェックツールも備えています。

![KSA の飛行画面。簡体字中国語 UI で、English・日本語・简体中文 を並べた Language メニューを開いた状態](docs/images/language-menu-zh-CN.webp)

*飛行中の画面（簡体字中国語 UI）。Language メニューから English・日本語・简体中文 を切り替えられます。*

**現在のバージョン: v0.8.0 プレビュー版。Windows x64、KSA 2026.10.7.5541 / 2026.10.10.5554 に対応します。** 翻訳は UI の一部が対象です。未対応の画面や訳文のない項目は英語で表示されます。

## ダウンロードとインストール

[v0.8.0 をダウンロード](https://github.com/LiX-Works/KsaUiLanguages/releases/tag/v0.8.0)し、**KsaUiLanguages-0.8.0-installer6-win-x64.zip** を選んでください。

1. 上記の対応バージョンの KSA を用意し、通常どおり起動できることを確認します。
2. ZIP をすべて展開し、ゲームを終了してから **Install.cmd** を実行します。**KSA.dll** があるゲームフォルダーを選択してください。
3. デスクトップの **「KSA UI Languages (5554)」** または **「KSA UI Languages (5541)」** から起動します。名前は選択したゲームのバージョンによって変わります。
4. ゲーム内で **Language → English / 日本語 / 简体中文** から言語を選択します。選んだ言語は次回の起動時にも使われます。

インストーラーの案内は英語です。同梱ライセンスに同意する場合は、確認画面で **Yes** を選んでください。必要なローダーと専用ランタイムを同梱しているため、オフラインでインストールできます。管理者権限は不要です。Install.ps1 をダブルクリックするとテキストエディターで開く場合があるため、Install.cmd を使ってください。

**同じゲームバージョンで更新する場合**は、元のゲームフォルダーを選択します。設定、セーブデータ、起動時の言語は保持され、設定ファイルと旧プラグインはバックアップされます。セーブデータの自動バックアップは行いません。v0.6.0 以前から更新すると、デスクトップの「KSA 中文版」ショートカットは新しい名前に置き換わります。

**5541 から 5554 へ移行する場合**は、Build5541 を残して専用の Build5554 環境を作成します。両方のゲームフォルダーを保管してください。このインストーラーはゲーム本体の更新・バックアップや、旧セーブデータの自動移行を行いません。[インストール・セーブデータ・アンインストールの詳細（英語）](docs/INSTALLER.en.md)

## 最近の更新

- **v0.8.0 — 英語のインストールガイド**: インストール・更新・アンインストールの詳しい説明に英語版（[docs/INSTALLER.en.md](docs/INSTALLER.en.md)）を追加しました。

v0.7.0 から:

- **選んだ言語を記憶**: Language メニューで選んだ言語が、次回の起動時の言語になります。
- **英語のインストーラー**: インストール・起動・アンインストールの案内を英語にし、デスクトップのショートカット名を「KSA UI Languages (ビルド番号)」に変更しました。
- **インストール時の起動言語**: 新規インストールでは Windows の表示言語に合わせ、日本語の Windows では日本語、中国語の Windows では簡体字中国語、それ以外では英語で起動します。更新時は既存の設定を引き継ぎます。スクリプトでインストールする場合は `-Locale ja-JP`、`zh-CN`、`en-US` を指定できます。

## 対応言語

- **3 言語に対応**: 日本語を追加し、簡体字中国語と元の英語を引き続き利用できます。日本語・中国語の辞書はそれぞれ **1,625 項目**で、既存の翻訳機能が扱う設定、エディター、主な HUD、計画、軌跡、セーブ画面、説明文などを対象としています。
- **日本語の案内**: ようこそ画面で仮名や日本語の句読点を含む文章の改行を改善し、表示に必要なフォントの文字を追加しました。
- **識別に必要な表記を保持**: RCS、EVA、Isp、TWR、HUD、Δv などの略語、単位、キー割り当て、パーツの型番、プレイヤーが付けた名前は保持します。

起動時の言語は、インストール先の `instance/mods/KsaUiLanguages/language.json` に `locale`（`ja-JP`、`zh-CN`、`en-US`）として保存され、Language メニューで切り替えると自動で更新されます。

## 確認内容と既知の問題

同じ配布用プラグインで、両対応バージョンともに **60 項目の言語・UI 自動チェック**に合格しました。インストーラーは **25 項目（5541）と 23 項目（5554）の隔離したインストール・更新・アンインストールのチェック**に合格しています。一部に英語が残り、長いラベルやセーブ名が切れる場合があります。日本語は共通の Noto Sans SC フォントで表示するため、一部の漢字が中国語の字形になります。すべての操作や長時間のプレイは全面的には検証していません。[確認内容と既知の問題の詳細](docs/RELEASE_NOTES_v0.8.0.md)

非公式のコミュニティ製言語パックです。**KSA 本体と Starship 機体 MOD は含みません。** 次回以降の公開バージョンは 0.1 ずつ進みます。[バージョン番号の方針（中国語）](docs/VERSIONING.md)
